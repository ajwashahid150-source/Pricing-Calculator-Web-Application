## 📌 Project Overview

**Premium Pricing Calculator** is a modern, responsive, and interactive web application built using **HTML5, CSS3, Bootstrap 5, and Vanilla JavaScript**.

The application instantly calculates:

- Product Subtotal
- Discount Amount
- Tax Amount
- Final Total

without refreshing the page, providing a smooth and professional user experience.

# 🧮 Pricing Formula

```text
Subtotal = Price × Quantity

Discount Amount = (Subtotal × Discount%) / 100

Price After Discount = Subtotal − Discount Amount

Tax Amount = (Price After Discount × Tax%) / 100

Final Total = Price After Discount + Tax Amount
```
